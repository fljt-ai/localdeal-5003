# LocalDeal 前端

这是 LocalDeal 本地课程演示的浏览器界面，包含门店发现、点评、优惠购买、券包、个人中心及商户核销。

请按[项目运行说明](../README.md)启动后端，再使用说明中的本地网址打开页面。前端通过 `src/http-api.js` 访问后端，账号、收藏、点评及订单由 SQLite 保存；购买使用模拟支付。

`src/i18n.js` 管理中英文界面与虚构示例目录翻译。默认英文；语言选择保存在浏览器 localStorage（只有语言键），不影响会话或 SQLite 数据。用户输入的昵称、邮箱和点评保留原文，常见英文搜索词映射到已有目录关键词。

前端需要后端提供服务，请勿直接双击 `index.html` 或使用 `file://` 打开。安装、演示账号及完整操作流程均见[项目 README](../README.md)。

列表按页从服务器读取：门店、优惠和收藏每页 12 条；点评、个人订单和商户订单每页 10 条。页面提供上一页、下一页和完整结果数量。搜索、地区、类别、评分、订单状态及排序由后端处理；切换条件会回到第一页。搜索输入延迟 300 毫秒提交，过时的请求结果不会覆盖当前页面。

门店平均分、全部点评数和个人统计由服务器计算；用户自己的点评独立于单店点评的当前页，可以继续修改。购买前重新读取优惠，模拟购买的重试沿用同一订单标识。详细接口见 [API-CONTRACT.md](docs/API-CONTRACT.md)，验证范围见 [FRONTEND-CHECKS.md](docs/FRONTEND-CHECKS.md)。

可选的前端回归检查只需要 Node（18 或更新版本），不需要安装第三方依赖：在项目根目录执行 `node frontend/tests/http-api.test.js` 和 `node frontend/tests/app-state.test.js`。运行应用本身仅需要项目 README 中说明的 Python。
