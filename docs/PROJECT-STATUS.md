# 项目进度与后续交付

更新时间：2026-10-03。方向为课程 Track 1：数据库应用开发。

## 当前完成

LocalDeal 已有连接 SQLite 的网页和 Python 后端，支持访客浏览、密码登录、顾客注册、收藏、点评、个人资料、模拟购买、个人券包、授权商户核销与本人数据导出。应用结构为 16 张表和 3 个视图，包含键、外键、检查约束、索引、事务和历史保护触发器。

核心数据库 18 项与 HTTP 26 项测试通过。实际网页已完成购买到核销的操作验证；服务重启后业务记录保留。列表现已分页，搜索与筛选在 SQL 中执行，初始化不再加载全部点评；完整评分、总数和个人导出保留。完整范围见 [验证记录](../database/docs/VALIDATION.md)。

启动、示例账号、备份和重新运行步骤见 [README](../README.md)；操作顺序见 [演示指南](DEMO-GUIDE.md)。
