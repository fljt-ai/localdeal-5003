# 项目进度与后续交付

更新时间：2026-11-27。方向为课程 Track 1：数据库应用开发。

## 当前完成

LocalDeal 已有连接 SQLite 的网页和 Python 后端，支持访客浏览、密码登录、顾客注册、收藏、点评、个人资料、模拟购买、个人券包、授权商户核销与本人数据导出。应用结构为 16 张表和 3 个视图，包含键、外键、检查约束、索引、事务和历史保护触发器。

核心数据库 18 项、HTTP 29 项测试、1 项丰富数据生成测试及两个前端检查脚本通过。新增可解释推荐、群体聚餐匹配和商户经营分析；实际网页确认三个入口和关键交互。并发事务实验完成 15 次独立验证。原有购买、核销、持久化和分页仍通过回归测试。完整范围见 [智能功能设计与验证](SMART-FEATURES.md) 和 [原验证记录](../database/docs/VALIDATION.md)。

启动、示例账号、备份和重新运行步骤见 [README](../README.md)；操作顺序见 [演示指南](DEMO-GUIDE.md)。
