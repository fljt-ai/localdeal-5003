# LocalDeal 演示指南

本指南说明如何演示当前本地全栈应用，不是已经录制的视频或最终课程报告。门店和示例账号为虚构资料，购买使用模拟支付；页面操作会保存到 SQLite，重复演示时既有记录会保留。

## 1. 启动并浏览门店

双击根目录 `start.command`，等待终端显示启动地址，在浏览器打开 [LocalDeal](http://127.0.0.1:8787)。保持终端运行；不要直接打开 `frontend/index.html`。

访客可浏览六家分店、查看菜单、平均评分和点评。演示地区、餐饮类别、价格排序及搜索关键词筛选，再打开 Harbor Bites 中环店查看套餐与条款。平均评分由实际点评计算，不是另设的展示数字。

## 2. 使用顾客账号

进入“个人中心”，点击“登录账号”，填写：

| 项目 | 示例 |
| --- | --- |
| 邮箱 | `alex@example.com` |
| 密码 | `LocalDealDemo!2026` |

登录成功后进入个人中心。查看已有收藏、自己的点评和券包，再收藏一家其他分店。可以使用“修改昵称”展示个人资料更新与点评显示名称的关联。

如要演示注册，退出后选择“注册新账号”，使用一个尚未注册的示例邮箱、昵称与 12–128 字符密码。注册账号的收藏和券包从空列表开始，没有商家工作台权限。之后退出并重新登录 Alex，继续下方购买步骤。

## 3. 新增、编辑与删除点评

使用 Alex 打开一家自己尚未评价的门店，例如全新示例中的 Harbor Bites 尖沙咀店。选择评分并写至少五个字符的点评，提交后查看点评列表及评分变化。通过自己的“修改点评”按钮编辑，再演示删除。

每位用户在每家店只能有一条当前点评。如果该店已经有自己的点评，“写点评”会进入已有记录的编辑。其他用户的点评没有编辑和删除入口，服务端也会检查作者身份。

## 4. 模拟购买并取得券码

打开 Harbor Bites 中环店的优惠，点击“查看优惠”，确认对应分店、价格、条款和有效期，再点击“确认模拟购买”。页面转入“我的券包”，出现新的待使用订单和券码；优惠库存减少一份。

复制刚购买的券码，留给下一步核销。购买不收取真实款项，保存的是课程演示订单。若连接中断，可以再次确认当前购买窗口；同一窗口沿用购买请求标识，不重复扣库存。关闭并重新打开购买窗口是新的购买意图，会生成另一张券。

新数据库中 Alex 原有三个订单分别演示待使用、已核销和已过期。重新打开页面或重启服务后，仍应看到自己保存的业务记录；以后日期变化时，状态会按实际到期情况调整。

## 5. 换商户账号核销

从个人中心退出 Alex，使用以下账号登录：

| 项目 | 示例 |
| --- | --- |
| 邮箱 | `harbor.owner@example.com` |
| 密码 | `LocalDealDemo!2026` |

此账号出现“商家工作台”。进入工作台，门店选择仅包含该账号获员工授权的 Harbor Bites 分店。先选择中环店，粘贴刚取得的券码并确认核销。

核销成功后，台账对应订单显示“已核销”。这里显示授权门店全部买家的订单，商户个人券包仍只属于商户自己的账号。退出后重新登录 Alex，在自己的券包查看同一订单的新状态。

## 6. 展示业务限制

这些步骤会产生预期的错误提示，不应该新增订单或核销记录：

- 在核销前选 Harbor Bites 尖沙咀店，提交中环店券码，显示门店不匹配。
- 成功核销后再次提交同一券码，显示不能重复核销。
- 使用普通顾客账号尝试进入商户路由，不会获得商户订单与核销权限。
- 使用 `coffee.owner@example.com` 登录并选择 Daily Grind 尖沙咀店，提交初始过期示例 `LD-COFFEE03`，显示已过期。该账号同样使用公开示例密码；过期日期来自购买快照，即使当前店内优惠有效，旧订单也不会恢复可用。

无效库存、过期优惠、重复请求冲突及越权点评等更细的边界由数据库和 HTTP 测试覆盖；演示指南本身不代替测试通过记录。

## 7. 导出与查看数据库

在个人中心选择“导出我的数据”。文件只包含当前用户的资料、订单、收藏和本人点评及元数据，不包含其他买家的券包、商户台账、密码哈希或会话凭据。

停止服务后，可以使用已安装的 SQLite 查看工具打开 `database/localdeal.db`，查看 16 张表和三个视图。重点观察：

- `orders` 的实付金额与到期日快照，以及本次新增订单。
- `coupons.available_stock` 的变化。
- `redemptions` 的订单、员工与核销时间。
- `store_summary`、`coupon_catalog` 和 `wallet` 的组合结果。
- `sessions` 中的令牌摘要和过期时间；原始 Cookie 令牌不存入数据库。

完整关系源码见 [16 表 Mermaid](../database/docs/ER-DIAGRAM.md)；现有 [SVG](../database/docs/er-diagram.svg) 专门展示不含会话表的 15 表核心模型。

## 8. 重启与结束

按 Control+C 停止服务，再次启动后数据会保留；应用不提供恢复初始资料按钮。若需要独立的全新示例，可从项目目录运行 `python3 -B run.py --db database/another-demo.db --port 8788`，使用尚不存在的文件名，再打开新端口地址。它不会覆盖原数据库。

演示结束后停止服务。若继续撰写报告或录制视频，应记录自己的操作结果、模型分析和辅助工具使用；本包尚未代替这些最终交付。
